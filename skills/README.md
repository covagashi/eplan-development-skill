# skills/

The skill collection, organized by EPLAN product:

| Product | Folder | Scope |
|---------|--------|-------|
| EPLAN Electric P8 | [`eplan-p8/`](eplan-p8/) | C# scripting, EPLAN API, Remote Client automation |
| EPLAN EEC Pro | [`eec-pro/`](eec-pro/) | Typicals, mechatronic model, formulas, generation |

Each skill is a folder with a `SKILL.md`. The folder name must equal the skill's
`name` frontmatter field. The router lives in [`../router/`](../router/).
